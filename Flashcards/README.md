# Flashcards

Spaced-repetition flashcards for the Windows Privilege Escalation module, in the Obsidian spaced-repetition `Question::Answer` format. Two decks split enumeration/foundations from exploitation; review them to lock in the enumerate → identify → exploit reflex for OSCP/PNPT/CRTP-style exams.

## Decks
- [Enumeration & Foundations](Windows-PrivEsc-Enumeration-and-Foundations-Flashcards.md) — methodology, `whoami /priv`, groups, services, UAC, tools.
- [Exploitation](Windows-PrivEsc-Exploitation-Flashcards.md) — token privileges, potatoes, services/registry, UAC bypass, kernel/CVEs, credentials.
